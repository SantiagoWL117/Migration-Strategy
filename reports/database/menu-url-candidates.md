# Menu URL Candidates - Quick Reference

## Strategy
During audits, if a menu link is needed, try these candidate URLs in order. This speeds up the process without sacrificing quality.

## URL Pattern Priority (try in this order):
1. `{name-slug}ottawa.menu.ca/?p=menu` - Most common
2. `{name-slug}.menu.ca/?p=menu` - Second most common  
3. `{name-slug}.ca/?p=menu` - Common alternative
4. `m.{name-slug}ottawa.com/menu` - Mobile subdomain
5. `{address-number}{name-slug}.ca/?p=menu` - Address prefix pattern
