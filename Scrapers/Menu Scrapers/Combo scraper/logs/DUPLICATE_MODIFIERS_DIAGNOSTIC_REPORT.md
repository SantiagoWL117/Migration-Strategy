## 🛠️ Cleanup Strategy

### SQL to Find Duplicates
```sql
SELECT 
    mg.id as modifier_group_id,
    m.name as modifier_name,
    array_agg(m.id ORDER BY m.id) as modifier_ids,
    COUNT(*) as duplicate_count
FROM menuca_v3.modifiers m
JOIN menuca_v3.modifier_groups mg ON mg.id = m.modifier_group_id
WHERE m.deleted_at IS NULL AND mg.deleted_at IS NULL
GROUP BY mg.id, m.name
HAVING COUNT(*) > 1
ORDER BY duplicate_count DESC;
```

### Cleanup Approach
For each set of duplicates:
1. **Keep** the FIRST modifier (lowest ID) - it likely has the correct prices linked
2. **Delete** the extra duplicates
3. Clean up orphaned `modifier_prices` records

### Sample Cleanup SQL (for review)
```sql
-- Soft delete duplicate modifiers (keep first one)
WITH duplicates AS (
    SELECT 
        modifier_group_id,
        name,
        MIN(id) as keep_id,
        array_agg(id ORDER BY id) as all_ids
    FROM menuca_v3.modifiers
    WHERE deleted_at IS NULL
    GROUP BY modifier_group_id, name
    HAVING COUNT(*) > 1
)
UPDATE menuca_v3.modifiers m
SET deleted_at = NOW()
FROM duplicates d
WHERE m.modifier_group_id = d.modifier_group_id
  AND m.name = d.name
  AND m.id != d.keep_id
  AND m.deleted_at IS NULL;
```
